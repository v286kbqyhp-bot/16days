# 武器大全
其中武器的选择范围是指角色可以让攻击效果发生在哪里，而效果范围是指一些武器可能会对多格造成伤害或位移。当效果范围为1时，则只会对所选的目标格生效。

> **状态说明**：本页所列武器、符文及数值均为**首版候选方案与首轮试算（待确认）**，供首战原型与 [[美术需求清单]] 对接。

## 武器表

设计思路参考《陷阵之志》虫洞行者（Rift Walkers）的基础武器配置：所有武器均附带 **推动 1 格** 的位移效果（暂不做推 2 格），仅少量武器拥有高直接伤害，通过**选择范围**与**效果范围（推动形态）**区分定位。
