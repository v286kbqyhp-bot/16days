## 1. 已定风格方向与分层思路

- **总体美术风格（已定方向）**：采用 **像素风格**（基于 3D 低多边形素材 + 三渲二像素化 Shader，配合 2D 手绘像素图标与界面）。
- **细节分层思路**：参考《潜水员戴夫》（*Dave the Diver*）——
  - **玩法盘面层（克制、高可读）**：8×8 战棋盘面、地形块与盘面小人减少杂乱碎噪点，每个地形格控制在 3–4 个干净色阶，优先看清格界、单位朝向、地精攻击预告与 1 格推动落点。
  - **交互与反馈层（丰富、有表现力）**：营地站点面板、角色识别头像、武器/符文/纹章图标，以及铁匠强化、战果缴税等交互反馈，可根据工时手绘 2D 像素画丰富细节。
- **画面、交互与资产清单**：具体界面串联、营地四个站点构图及待交付资产清单见 [[美术需求清单]] 与 [[营地场景设计]]。以下色板、艺术家参考与渲染参数为**候选执行参考（待首版样片实测确认）**。

## 3. 三渲二像素化与分层渲染候选参数（待样片确认）

为满足 [[美术需求清单]] 第 18、19 节“Godot 4.7.2、Compatibility、Windows 10 x64、统一像素化参数以及格子标记和文字的可读性”要求，首版样片建议按以下结构测试：

1. **3D 像素化层与 UI 高清层分离**：
   - 3D 战场与营地场景置于低分辨率 `SubViewport`（候选基准分辨率 `480×270` 或 `640×360`，按整数倍 `Nearest` 缩放至窗口分辨率）。
   - 3D 材质关闭光滑塑料高光，采用 2–3 阶硬明暗色阶 + 1px 深度外描边 Shader。
   - 界面文字、数值、按钮与棋盘战术标记置于顶层原生分辨率 `CanvasLayer`，手绘像素图标按整数倍 `Nearest` 放大，防止中文字体与数字被像素 Shader 糊掉。
2. **六种地形的“底色 + 像素纹样”区分建议**：
   - **普通地**：暗暖灰褐泥土，格界清晰，无杂物噪点。
   - **草地**：深松绿底 + 2–3 簇亮绿像素草叶；点燃后叠加 3–4 帧像素火苗与焦黑地表。
   - **水地**：深青蓝水面 + 1px 亮青水岸线与横向波纹。
   - **石地**：高出格面的冷灰像素大石块（明暗面分明）；撞击 1 次出现深色像素裂纹，2 次碎裂变回普通地。
   - **沙地**：暖沙黄底 + 斜向像素沙垄纹；触发沙尘时浮现半透明像素黄雾与禁攻标记。
   - **地洞**：内凹锯齿状深黑洞口，形状与颜色上严格区分于“地精钻出预告格”（橙红裂纹/箭头）。
