# 《陷阵之志》机甲、武器与驾驶员强化手册

**适用范围**　原版战役及 Advanced Edition（AE），含秘密战队。按开局战队查机甲，按装备名查改装，按驾驶员查技能。随机战队和自定义战队复用同一批机甲。任务友军、建筑、防御坦克和武器召唤物不单列为可选机甲。

## 1　一个核心可以用在哪里？

| 投入位置         | 获得什么                        | 换装后归属                       |
| ------------ | --------------------------- | --------------------------- |
| 给一台机甲安装反应堆核心 | 该机永久增加 1 格可分配能源，本时间线内有效     | 核心装入后绑定机甲；战斗之间可关闭节点，把能源重新分配 |
| 机体生命节点       | 1 格能源开启，生命上限 +2             | 属于机体；每台一个节点                 |
| 机体移动节点       | 1 格能源开启，每回合移动 +1 格          | 属于机体；每台一个节点                 |
| 武器本体及 A、B 改装 | 本体按启动费供能；各改装可分别点亮，同时开启时费用相加 | 改装选项随装备走，供电由当前机甲承担          |
| 驾驶员          | 固有技能随人，部分需单独供能；升级技能靠经验获得    | 换机后按新座机和装备重新计算              |
| 战队被动         | 例如让烟雾伤敌、让友军免疫火焰             | 装在一台机甲的装备槽中；作用对象按被动说明判断     |
| 输电网          | 电量承受建筑损失，电网防御提供抵消伤害的机会      | 全队共用，独立于单机反应堆               |

**读表示例。** 战斗机甲开局生命 3、移动 3。拿到第一个核心，可以将它配给生命节点得到 5 生命，也可以配给移动节点得到 4 移动。泰坦之拳的突进要 2 格能源，伤害 +2 要 3 格；两项都开共 5 格。多余核心的价值取决于能否凑够下一个节点。

每台机甲有 **2 个装备槽**，主动武器和被动装置共用。普通机甲安装其他专属类别武器，启动费额外 **+1**；通用装备、被动通常没有普通机甲之间的职业罚费。秘密战队的电子人使用非电子人装备也要多供 1 格，包括通用和被动。战斗之间可把装备移到另一台机甲。飞行、装甲等机体特性从开局生效。

## 7　战役内获取与跨局保留

| 时机 | 玩家选择 | 数量、花费及作用 |
|---|---|---|
| 选择任务 | 查看任务卡上的奖励图标 | 企业声望用于岛末购物；电力补充全队输电网；标有核心的目标直接奖励核心。按目标单列结算 |
| 普通时间胶囊 | 用机甲进入所在格回收，或保护完好的胶囊到战斗结束 | 每个至少 1 核。脚本中的十张奖励牌为仅 1 核 ×3、1 核＋随机装备 ×4、1 核＋随机驾驶员 ×3；从牌堆抽走，不能把比例视为每次独立概率 |
| 完美岛屿 | 完成所选任务的全部目标及总部目标 | 岛末额外三选一：一件装备、一位驾驶员、或电网电力（常规 2 格；Unfair 难度电力获取翻倍）。无需打遍地图所有区域；建筑受损本身只在影响任务目标时破坏完美条件 |
| 企业商店 | 岛末用本岛声望补强，离岛前结清 | AE 常规武器 2 声望，1 个核心 3 声望，1 格电网电力 1 声望；前两个岛的武器选择较少。电网已满时继续补电可提高电网防御 |
| 回收装备与驾驶员 | 捐出不再使用的物品换声望 | 常规装备通常换 1 声望；大众英雄驾驶员可换 4。出售和购入使用声望；让买到的装备生效另算反应堆供能 |
| 每场战斗 | 使用修理、护盾、强化、酸液及队伍被动 | 常规修理消耗一次行动，回复 1 生命并清除火、冰、酸液。护盾抵挡一次有效攻击；强化通常使下次攻击伤害 +1；酸液能放大目标受到的武器伤害。此类战术效果不写入机体基础值 |
| 一条时间线结束 | 选择一名符合条件的幸存驾驶员前往下一条时间线 | 保留该驾驶员的经验和已获技能。机体供能、武器、库存和声望随时间线重置；已解锁的驾驶员和用成就币解锁的战队保留为以后开局选择 |
