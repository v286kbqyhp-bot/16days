# UP 纹章：立体红字与黄橙放射背景

2026-11-27，作者选定已展示的黄橙放射纹参考，并补充 UP 需要高光、暗部与立体感。本稿采用红色正面、左上倒角亮面、右下暗面及向右 1 像素／向下 2 像素的侧面厚度，整体外缘仍为一像素描边。背景是两色放射纹，圆盘边缘同步采用浅黄高光与棕黄阴影，几何完全沿用作者圆盘模板。
