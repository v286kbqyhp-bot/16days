# 普通纹章第三版草稿

2026-11-27，按作者「首先改普通的」要求，仅修改普通纹章，供下一轮审阅。

沿用四角星主题，改成更大的空心记号；底盘、边缘、图案统一为灰青色系；移除原有奶白色填充、近黑色描边与双重内圈。保持 48 × 48 透明底、四个可编辑图层，尚无动画、法线或游戏接入。`pins-v2` 的全部文件保持原样。

`crest_common.pxo` 为 Pixelorama 原件，`crest_common.png` 为静态图，`普通纹章_新旧对比.png` 同时展示最近邻放大图与原尺寸。

AI 辅助制作方式：`author_common.gd` 在 Pixelorama 1.2.4 的原生 Project / PixelLayer / PixelCel 环境执行，复用上一版 `author_pins.gd` 的绘制和保存辅助方法；不是鼠标逐点手绘。Pillow 仅用于审阅图排版。已目视检查对比图，并验证四层原件合成与 PNG 逐像素一致，以及上一版全部文件哈希未变。本次未额外打开 GUI 检查。
