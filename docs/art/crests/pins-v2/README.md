# 圆形吧唧纹章 · 静态初稿

2026-11-27，按作者要求制作全部 17 枚纹章的原始静态状态，供逐枚修改。设计依据为 `docs/design/纹章设计文档.md` 的首版候选名单；名称和能力以该文档为准。本目录为待作者审阅的美术草稿，尚未接入游戏。

- `纹章总览.png`：带编号、名称的审阅图，同时显示 3 倍最近邻放大与原始尺寸。
- `全部纹章_静态初稿.pxo`：336 × 168 总览，每枚纹章一个独立图层；已在官方 Pixelorama 1.2.4 界面打开并核对 17 枚显示。
- `crest_*.pxo`：17 个 48 × 48 可编辑原件，每个包含「底盘轮廓」「金属包边」「纯色印刷底」「能力图案」四层。
- `crest_*.png`：对应透明底静态导出。
- `manifest.json`：编号顺序、游戏 ID、名称与尺寸清单。
- `author_pins.gd`：AI 辅助绘制的源脚本。图案通过 Pixelorama 原生 Project、PixelLayer、PixelCel 与保存接口批量制作，并非逐点鼠标手绘。审阅总览的排版和文字由 Pillow 合成，未用它绘制纹章。

## 本次范围

采用统一圆形胸针正面轮廓、细包边和纯色印刷图案。普通纹章用灰色边框，其余采用同一套黄铜色边框，中央图案依照能力区分。没有渐变、投影、烘焙扫光、动画或材质 shader；法线贴图尚未制作。背面别针也不在此次正面静态图范围中。

本批为原创草稿，没有复制 Balatro 的像素素材。Balatro 的资源研究与其纹理、shader 结论另见相邻 `balatro-review-20261127/`，不能将本批制作方式描述为对其完整技术路线的复刻。

## 工具与检查

Pixelorama 1.2.4 源码版本 `f3cb9ab2065042ba6b31beee4204221ff9006d50`。在临时源码副本修正若干变量类型推断兼容问题后，以 Godot 4.7.2 运行 Pixelorama 并调用上述原生接口保存；随后使用官方发布版 Pixelorama 1.2.4 打开总览核对。源码兼容修改未进入游戏工程。
